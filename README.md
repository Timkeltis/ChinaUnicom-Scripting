# ChinaUnicom-Scripting

中国联通余量查询 Scripting 小组件完整源代码。

## 功能

- 查询剩余话费、通用流量、定向流量和语音余量
- 支持小号、中号和大号组件
- 支持 BoxJS 同步中国联通 Cookie
- 支持缓存及失败时旧缓存回退
- 支持多种小号组件样式

## 安装

将仓库全部文件作为一个项目导入 Scripting App。

## 隐私

仓库不包含用户 Cookie、手机号或运行时缓存。登录凭据仅保存在用户设备或 BoxJS 中。
